##  TypingPod
Experiment with typing biometrics to create a unique user authentication system based on individual typing patterns.

## Project Description
The general idea of the project is to explore the use of typing biometrics for user authentication. The system will analyze individual typing patterns, such as speed and rhythm, to create a unique profile for each user. This profile can then be used to verify the user's identity during login attempts / 2FA escalation, providing an additional layer of security beyond traditional passwords/etc.



## Tech Stack
pytorch, python, javascript, fastapi, google collab, GCP, github



## Objectives
- Collect typing data from users to build a dataset of typing patterns.
- Develop machine learning models to analyze typing patterns and create unique user profiles.
- Implement an authentication system that uses typing biometrics for user verification.
- Test the system with real users to evaluate its accuracy and reliability.
- Explore potential applications of typing biometrics in various security contexts.
